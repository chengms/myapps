# eMMC 固件开发工程

本工程提供一个面向嵌入式 SoC 的 eMMC 固件参考实现，包含自研控制层、硬件抽象层与寄存器仿真环境，便于在缺乏真实硬件的情况下开展先行验证与功能开发。

## 功能概览
- 基于 JEDEC eMMC 5.x 规范的寄存器模型与关键位定义
- 控制器初始化、复位、命令发送、数据读写等核心流程的固件逻辑
- 可在主机端运行的寄存器仿真层，支持断言、日志与单元测试
- 可扩展的平台适配层，供后续接入真实芯片或 RTOS 驱动
- 简单的冒烟测试示例，演示初始化与块读写流程

## 目录结构
```text
emmc-firmware/
  ├── docs/                # 设计文档与规范说明
  ├── firmware/            # 固件源代码
  │   ├── include/         # 对上层开放的头文件
  │   └── src/             # 控制定序、协议实现
  ├── hal/                 # 硬件抽象层（可替换）
  │   ├── include/
  │   └── src/
  ├── platform/            # 平台适配与启动相关代码
  ├── scripts/             # 构建与辅助脚本
  ├── sim/                 # 寄存器/硬件仿真实现
  ├── tests/               # 测试与示例程序
  └── Makefile             # 顶层构建入口
```

## 构建与运行
1. 安装依赖：POSIX shell、`gcc` 或 `clang`、`make`。
2. 在工程根目录执行 `make`，默认会生成仿真目标 `build/emmc_sim`。
3. 运行 `./build/emmc_sim`，查看仿真日志与断言输出。

常用命令：
- `make clean`：清理构建产物
- `make test`：编译并执行测试用例（当前等价于运行冒烟测试）
