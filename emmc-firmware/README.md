# eMMC Firmware Simulation

本工程用于模拟现有芯片上的 eMMC 存储固件开发流程，提供了寄存器抽象、主控驱动以及基础单元测试，帮助在真实硬件前完成接口联调和算法验证。

## 功能特性

- 模拟 SDHCI 风格的主控寄存器组，支持命令寄存器、状态寄存器、中断寄存器等关键字段。
- 提供 `emmc_controller` 驱动层，涵盖初始化、单块读写与错误检测。
- 通过 `sim/emmc_hw_sim.c` 在内存中模拟 eMMC 闪存阵列，可配置容量并即时响应寄存器访问。
- 自带基础示例程序 `src/main.c` 与测试用例，方便快速验证读写链路。

## 目录结构

```
include/          对外头文件（控制器 API、寄存器定义）
sim/              硬件寄存器与存储阵列的内存级模拟
src/              控制器驱动与示例程序
 tests/           C 语言单元测试
 docs/            设计文档与寄存器说明
 tools/           预留的脚本与辅助工具目录
```

## 快速开始

```bash
cd emmc-firmware
make          # 构建模拟程序
make run      # 运行示例程序
make test     # 执行单元测试
```

示例程序会在块地址 0 写入一段模式数据，再读回验证一致性：

```
eMMC simulation succeeded. First byte: 0x00
```

## 后续扩展建议
