# eMMC固件开发工程 - 项目总结

## 项目概述

本项目是一个完整的�MMC（Embedded Multi-Media Card）固件开发工程，提供了从底层寄存器操作到高层驱动接口的完整实现。项目采用模块化设计，分层架构，便于理解、测试和移植。

**创建日期：** 2025-11-13  
**版本：** 1.0  
**开发语言：** C (C99标准)

- 寄存器定义完整（基于JEDEC eMMC 5.1规范）

## 核心功能

### 1. 寄存器层 (emmc_regs.h)

**功能：**
- 定义所有控制器寄存器地址
- 定义寄存器位域和标志
- 提供寄存器访问宏

**包含的寄存器：**
- 系统地址寄存器
- 块大小/计数寄存器
- 命令/参数寄存器
- 响应寄存器（4个）
- 数据端口寄存器
- 状态寄存器
- 控制寄存器（主机控制、电源、时钟等）
- 中断寄存器
- 能力寄存器
- DMA相关寄存器

**eMMC命令定义：**
- CMD0-CMD38 (30+命令定义)

### 2. HAL层 (emmc_hal.h/c)

**功能：**
- 硬件抽象和封装
- 寄存器读写操作
- 底层命令和数据传输
- 中断管理
- 电源和时钟控制

**主要接口（20+函数）：**
```c
emmc_hal_init()              // 初始化
emmc_hal_set_clock()         // 设置时钟
emmc_hal_set_power()         // 电源控制
emmc_hal_send_command()      // 发送命令
emmc_hal_read_data()         // 读数据
emmc_hal_write_data()        // 写数据
// ... 更多
```

### 3. 驱动层 (emmc_driver.h/c)

**功能：**
- 高层API接口
- eMMC协议实现
- 卡识别和初始化
- 块读写操作
- 状态管理

**主要接口（10+函数）：**
```c
emmc_driver_init()           // 初始化驱动
emmc_driver_read_blocks()    // 读块
emmc_driver_write_blocks()   // 写块
emmc_driver_erase_blocks()   // 擦除块
emmc_driver_get_card_info()  // 获取卡信息
// ... 更多
```

### 4. 模拟器 (emmc_sim.c)

**功能：**
- 模拟寄存器空间
- 模拟存储空间（32MB）
- 模拟卡行为
- 支持调试和开发

### 5. 测试程序 (test_emmc.c)

**测试用例：**
1. 驱动初始化测试
2. 卡信息获取测试
3. 单块读写测试
4. 多块读写测试
5. 块擦除测试
6. 驱动反初始化测试

## 移植步骤

1. **修改寄存器基地址**
   - 编辑 `inc/emmc_regs.h`
   - 设置 `EMMC_BASE_ADDR` 为实际地址

2. **实现平台相关函数**
   - `emmc_hal_delay_ms()`
   - `emmc_hal_delay_us()`
   - `emmc_hal_get_tick_ms()`

3. **配置时钟和电源**
   - 根据硬件调整时钟配置
   - 实现电源管理

4. **配置中断**
   - 注册中断处理函数
   - 配置中断优先级

5. **测试验证**
   - 运行测试程序
   - 验证读写功能
   - 压力测试
